# ToddlerTime

Website tontonan untuk anak balita, mirip YouTube Kids. Dibangun dengan Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, dan Supabase.

## Menjalankan secara lokal

```bash
npm install
cp .env.example .env.local   # isi kredensial Supabase & YouTube
npm run dev
```

Buka http://localhost:3000.

Detail stack, konvensi, design system, dan roadmap fitur ada di [CLAUDE.md](CLAUDE.md).
